# Generated imagery

Drop optional images here; the app picks them up automatically at build time
(no code changes needed) and falls back to the built-in SVG art when missing.

| Path | Used for | Spec |
|---|---|---|
| `species/<id>.webp` (`excoecaria`, `acanthus`, `pandanus`, `derris`) | Species cards, species page hero, map details | 1024×1024, transparent background, botanical illustration |
| `onboarding/hero.webp` | Welcome screen (replaces the live diorama on capable screens only if present) | 1600×1200, transparent background |

Prompts for every image are in `docs/redesign/image-prompts.md`.
Illustrations are **not** field photos: advisors must review them for
morphological accuracy before they are presented as reference material.
